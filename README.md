# ⚗️ LabQuim — Laboratorio Virtual de Química Orgánica

Plataforma web interactiva paso a paso para el estudio de mecanismos de reacción, nomenclatura IUPAC y resolución de exámenes de ingreso en Química Orgánica.

**Autor:** Univ. Juan Pablo Stumpfs Díaz

## Estructura del proyecto
- `index.html` — Interfaz principal y reproductor SVG interactivo.
- `labquim.json` — Índice maestro de unidades, menús y configuración global.
- `reactions/` — Base de datos modular en formato JSON con mecanismos paso a paso, banco de exámenes y ejercicios de nomenclatura.
